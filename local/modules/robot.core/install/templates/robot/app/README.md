Сборка стилей и статики на сборщике gulp (app)
===

## Краткое описание:
Frontend-сборка стилей, простых js-скриптов, статических изображений, иконок и глобальных javascript-плагинов 

## Техническая информация:
- **node** `>=20.11.0`
- **npm** `>=10.2.4`
- **Сборщик** - gulp `5.0.0`
- **Препроцессор** - sass `1.83.4`
- **Поддержка сборки**:
  - Стилей
  - Javascript
  - Статических изображений и иконок
  - Svg-sprite
  - Javascript-плагинов

## Команды для сборки:
- `npm run build` - полная сборка всего проекта
- `npm run styles` - сборка стилей
- `npm run scripts` - сборка javascript
- `npm run icons` - сборка картинок, иконок и svg-sprite
- `npm run dev` - полная сборка в режиме **watch**

## Структура проекта
- `/dist` - сборка bundle всех скриптов, стилей и тд
- `/fonts` - скрипты подключения шрифтов, не входят в сборку из-за необходимости поддержки отображения шрифтов, когда модуль находится в папке `/local` или в папке `/bitrix`
- `/img` - статические изображения, которые не входят в сборку
- `/src` - файлы, входящие в сборку:
  - `/assets` - иконки, шрифты, картинки
  - `/plugins` - глобальные js-плагины
  - `/scripts` - простые js-скрипты, доступные глобально по всему сайту
  - `/styles` - стилевые файлы (своя структура отражена внутри папки, просьба придерживаться её)
- `/video` - демо-видео контент
- `/gulpfile.js` - правила для сборки gulp
- `plugins.php` - регистрация `/app` как js-extention в рамках системы 1С-Битрикс
